Зелений. Критерій: `p85_date` 2027-01-21 не пізніша за `target_date` рядка `REL-1` 2027-01-22 (запас 1 день), і жодна з метрик дашборда не за своєю межею: MT-01 1 день при межі 5, MT-03 3 ризики при межі більше 3, MT-04 72 години при межі 100.

Запас до дати першого релізу лише один день (прогноз P85 2027-01-21 проти 2027-01-22), і він тримається всього на двох спринтах з однаковою швидкістю 8 points.

## 2. Як рахувалася симуляція

| Поле | Значення |
| --- | --- |
| Інструмент | власний скрипт Python, файл `simulate.py` у цій папці |
| Прогонів | 10000 |
| Що тягнеться випадково | velocity одного з моїх спринтів (`points_done`), з поверненням |
| Як рахується дата прогнозу | останній день спринта, на якому закінчується робота: для сценарію «весь перший реліз» кінець спринта 1 плюс (P − 1) × 14 днів, для сценарію залишку кінець останнього спринта плюс P × 14 днів |

Одна симуляція: беру залишок points, поки він більший за нуль, випадково вибираю velocity одного зі спринтів, віднімаю її від залишку і рахую спринт. Коли залишок дійшов до нуля або нижче, записую кількість спринтів. Після 10000 прогонів сортую результати, P50 це 5000-е значення, P85 це 8500-е. Код у файлі `simulate.py`, запуск: `python simulate.py velocity.csv <залишок>`.
